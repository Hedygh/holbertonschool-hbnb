# HBnB - Part 4 (Frontend)

## Overview

This part of the project focuses on building the frontend of the HBnB application using HTML, CSS, and JavaScript.  
The goal is to create a dynamic user interface that interacts with the backend API.

## Objectives

- Implement user authentication using JWT
- Fetch and display data from the API (places, details, reviews)
- Handle user interactions (login, filtering, adding reviews)
- Dynamically update the UI using JavaScript (DOM manipulation)

## Features

- Login system with JWT stored in cookies
- List of places with client-side filtering
- Detailed view of a place (info, amenities, reviews)
- Add review functionality for authenticated users
- Conditional UI based on authentication state

## Technologies

- HTML5 / CSS3
- JavaScript (Fetch API, DOM manipulation)
- REST API (Flask backend)
- JWT Authentication

## Notes

- The frontend communicates with the backend via HTTP requests
- CORS is required to allow frontend-backend interaction during development
